RAFAHSTUDIO — REVOLUÇÃO DOS PEDIDOS V1

Nesta versão o site foi atualizado preservando a estrutura existente.

1. TAGS DE PRAZO
- Prazo normal: mais de 7 dias
- Próximo: 4 a 7 dias
- Urgente: 2 a 3 dias
- Amanhã: 1 dia
- Entrega hoje: hoje
- Atrasado: prazo vencido, com pulso visual
As tags aparecem nos cards e também na visão de prazos.

2. KANBAN MAIS MODERNO
- Finalizados e as demais etapas agora possuem rolagem vertical própria.
- O quadro continua com rolagem horizontal para navegar entre as etapas.
- Cards ganharam efeito glass, elevação e destaque suave ao passar o mouse.

3. ARRASTAR PARA MOVER
- Segure um pedido e arraste para outra coluna.
- A coluna de destino ganha um destaque visual.
- Ao soltar, o status é atualizado, o histórico é registrado e o acompanhamento do cliente é sincronizado.
- As setas antigas continuam funcionando.

4. ACOMPANHAMENTO DO PEDIDO PELO CLIENTE
- Dentro de qualquer pedido existe o botão “Acompanhar pedido”.
- O RafahStudio cria um link privado exclusivo daquele pedido e já copia o link.
- O cliente não precisa de login.
- Ele vê somente o próprio pedido: projeto, serviço, prazo, status atual, progresso e jornada das etapas.
- A página do cliente atualiza automaticamente a cada 15 segundos.
- O valor do pedido não é mostrado na página pública.
- Os contatos públicos do designer aparecem para facilitar o contato.

5. IMPORTANTE — SUPABASE
Para ativar o acompanhamento, execute o arquivo supabase_setup.sql inteiro no SQL Editor do projeto Supabase.
A parte nova cria a tabela e as funções “order_tracking”.

6. TESTE RECOMENDADO
- Publique estes arquivos no GitHub Pages.
- Faça Ctrl+F5.
- Abra um pedido existente.
- Clique em “Acompanhar pedido”.
- Envie o link copiado para outro navegador/aba anônima.
- Mova o pedido de etapa no painel e atualize/aguarde a página do cliente: o status deve acompanhar.

Observação: esta é a primeira camada do acompanhamento. A próxima evolução pode incluir aprovação da arte pelo cliente, comentários, notificações em tempo real, botão “enviar alteração” e histórico visual com data/hora.
