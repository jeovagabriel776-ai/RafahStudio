RAFAHSTUDIO — PERFORMANCE 1.0

Principais melhorias desta versão:
- Renderização otimizada: ao mudar dados, o app reconstrói apenas a página atualmente aberta, em vez de todas as abas.
- Sincronização online menos agressiva: pausada quando a aba está oculta/offline e com intervalos maiores, retomando ao voltar para a página.
- Sincronização agrupada em ciclos para reduzir trabalho simultâneo.
- Catálogo remoto só redesenha quando os itens realmente mudaram.
- Imagens selecionadas em formulários usam Object URL para pré-visualização, evitando converter arquivos inteiros para Base64 e reduzindo uso de RAM.
- Imagens da tela recebem loading lazy/decoding assíncrono.
- CSS com content-visibility/contain para reduzir custo de listas grandes.
- Em telas pequenas, blur/glass foi suavizado e animações de entrada desativadas para melhorar desempenho.
- Respeita prefers-reduced-motion.
- Manifesto PWA reforçado com ícones PNG 192x192 e 512x512.
- Service Worker atualizado para novo cache de performance.

Importante:
- Nenhuma função de pedidos, clientes, catálogo, briefing, orçamento, financeiro ou acompanhamento foi removida.
- Notificações push reais com o aplicativo totalmente fechado ainda exigem Web Push/VAPID + backend; esta versão melhora as notificações já existentes.
