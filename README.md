# RafahStudio — versão UX corrigida

## Correções principais
- Corrigido o fechamento involuntário dos modais de Pedido, Cliente e Orçamento.
- Clique dentro dos campos não fecha mais o modal.
- O modal fecha somente pelo X, Cancelar, clique no fundo ou ESC.
- Corrigido o campo Instagram do cadastro de cliente.
- Corrigido o texto `[object Object]` no briefing interno de pedidos antigos.
- Adicionadas transições leves e foco visual nos campos.
- Mantida a identidade visual e a estrutura do RafahStudio.

## Logo
No `index.html`, procure por `logo-mark` e substitua o texto `R` pela sua logo quando quiser.
Uma pasta `assets/` pode ser criada para armazenar `logo.png`.

## Como testar
Abra `index.html` no navegador, entre na conta e teste:
Pedidos > Novo pedido; Clientes > Novo cliente; Orçamentos > Novo orçamento.
Preencha os campos sem fechar o modal. Salve normalmente.
