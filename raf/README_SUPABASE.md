# RafahStudio — Briefing online

1. No Supabase, abra SQL Editor e execute `supabase_setup.sql` inteiro.
2. Publique `index.html`, `app.js` e `style.css` no GitHub Pages.
3. Abra o RafahStudio pelo endereço HTTPS do GitHub Pages.
4. Entre na conta do designer.
5. Em Pedidos, clique em **Copiar link do briefing**.
6. Envie esse link ao cliente.
7. O cliente pode abrir no celular, preencher e enviar fotos.
8. O briefing e os arquivos vão para o Supabase.
9. O RafahStudio consulta os novos briefings a cada 30 segundos e cria o pedido.

Não use `file:///...` para gerar o link. O site precisa estar publicado em HTTPS.
