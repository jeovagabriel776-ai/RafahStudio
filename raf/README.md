# RafahStudio

Sistema web para designers gerenciarem pedidos, clientes, orçamentos, notificações e financeiro.

## Briefing online
O formulário público usa Supabase para receber dados e arquivos de clientes em celulares e outros computadores.

Consulte `README_SUPABASE.md` e execute `supabase_setup.sql` no projeto Supabase antes do primeiro teste.
